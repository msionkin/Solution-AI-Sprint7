## Ключевые решения

| | №1 | №18 | №10 |
|---|---|---|---|
| Готовность данных | Разрыв с планом закрытия: нет несмещённых меток | Разрыв с планом закрытия: нет эталона с привязкой к источнику | Разрыв с планом закрытия для модели (мало положительных); сверки — готово |
| Источник сигнала | Ранжирование без учителя + контрольная выборка 500 операций в месяц + разметка по гайдлайну (kappa ≥ 0,61) | Эталонный ввод андеррайтеров (≈ 300 пакетов) + бухгалтерские тождества | Расхождения с ГИР БО и оборотами + ≈ 300 синтетических подделок |
| Модель | Модель аномалий ± графовые признаки против двух baseline; бустинг-ранжировщик — после накопления меток | Открытые веса на 2 GPU: OCR + LLM, VLM, документная VLM + LLM; Excel — парсер | Детерминированные сверки + модель соотношений показателей на CPU; только флаг |
| Порог приёмки | precision@K ≥ 6% (×1,5 к baseline 4%) | ≥ 95% верных, «тихих» ошибок ≤ 1% | Полнота ≥ 80% при ≤ 10% помеченных пакетов |
| Пилот | Self-hosting в облаке на псевдонимизированных признаках (при вердикте комплаенса, иначе on-prem) | Self-hosting на арендованных GPU в облаке; открытые и синтетические документы; финалисты — на реальном эталоне on-prem | Облако; открытая БО и синтетика |
| Прод | On-prem, CPU | On-prem, GPU, те же модели | On-prem, общий конвейер с №18 |

## Сокращения

| Сокращение | Расшифровка |
|---|---|
| ГИР БО | Государственный информационный ресурс бухгалтерской (финансовой) отчётности ФНС |
| БО | Бухгалтерская отчётность |
| АБС | Автоматизированная банковская система |
| ПВК | Правила внутреннего контроля |
| ПОД/ФТ | Противодействие отмыванию доходов |
| 115-ФЗ, 152-ФЗ | Законы о ПОД/ФТ и о персональных данных |
| ПДн | Персональные данные |
| ИБ | Информационная безопасность |
| ИП | Индивидуальный предприниматель |
| ОКВЭД | Классификатор видов экономической деятельности |
| СБП | Система быстрых платежей |
| DPO | Data Protection Officer — ответственный за защиту персональных данных |
| KYC | Know Your Customer — внешняя платформа «Знай своего клиента» |
| OCR | Optical Character Recognition — распознавание текста |
| VLM | Vision-Language Model — модель, работающая с изображением и текстом |
| TF-IDF | Взвешивание слов по частоте в тексте и редкости в корпусе |
| precision@K, recall@K | Точность и полнота среди K операций с наивысшим приоритетом |
| Cohen's kappa | коэффициент Каппа Коэна — мера согласованности двух разметчиков с поправкой на случайное совпадение |
