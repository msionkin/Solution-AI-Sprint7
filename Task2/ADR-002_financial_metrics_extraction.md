# ADR-002. Извлечение финпоказателей на открытых моделях: пилот в облаке, прод on-prem

Статус: предварительное  
Дата: 2026-10-13  
Инициатива: 18. Извлекать финансовые показатели из неструктурированных бухгалтерских документов и банковских выписок

## Решение

**Данные.** Эталон — реальные пакеты (не меньше 40 документов в самом редком формате, предварительно около 300 пакетов), введённые андеррайтерами по гайдлайну со ссылкой на источник; хранится только on-prem. Для облака — БО юрлиц из открытого ГИР БО (отсканированная и сфотографированная) и синтетические выписки.

**Размещение.** Реальные пакеты содержат банковскую тайну и ПДн, поэтому за периметр они не выходят. Публичный API и выделенный контур провайдера отсечены: закрытые веса нельзя перенести в on-prem.
- Пилот — self-hosting открытых моделей на арендованных GPU в российском облаке, только на открытых и синтетических документах.
- Прод — on-prem на тех же моделях; закупка GPU идёт параллельно с пилотом.

**Модель.** Только открытые веса с лицензией для коммерческого использования, помещающиеся на узел из 2 GPU. Шортлист из трёх подходов:
- (A) OCR (PaddleOCR) + текстовая LLM;
- (B) VLM (Qwen3-VL 8B / 32B);
- (C) документная VLM (PaddleOCR-VL, dots.ocr) + небольшая LLM.

Кандидаты сравниваются в облаке по порогам из раздела 3 паспорта. Два финалиста подтверждаются на реальном эталоне on-prem. Excel и выгрузки бухсистем разбирает парсер, без модели.

## Допущения

| Допущение | Источник | Критично для вывода |
|---|---|---|
| GPU для on-prem можно закупить и запустить за 4–6 месяцев | Оценка | Да |
| Отсканированная командой открытая БО похожа на реальные сканы клиентов | Допущение | Да |
| Ручной ввод занимает существенную часть из 1,5 ч на пакет | Допущение | Да |
| DPO разрешит использовать архивные пакеты для эталона | Нет вердикта | Да |

## Триггеры пересмотра

- Комплаенс и DPO разрешают обработку реальных документов в облаке.
- Закупка GPU задерживается больше чем на 6 месяцев.
- Победитель облачного этапа теряет больше 3 п. п. на реальных данных.
