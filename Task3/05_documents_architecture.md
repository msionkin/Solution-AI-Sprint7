# №18 и №10. Архитектура сервисов кредитного конвейера (Container)

Решения по данным, размещению и модели — в [ADR-002](../Task2/ADR-002_financial_metrics_extraction.md) и [ADR-003](../Task2/ADR-003_forged_documents.md). На диаграммах показан целевой прод on-prem. Облачный этап пилота идёт только на открытой отчётности из ГИР БО и синтетике.

## №18. Извлечение финансовых показателей

Диаграмма: [18_container](diagrams/18_container.png).

**Где модель, а где код.** Модель нужна только для сканов, фото и PDF-сканов. Excel, выгрузки бухсистем и текстовые PDF разбирает парсер.

**Получение контекста** — отдельное звено. OCR определяет тип документа и отбирает 1–3 страницы с нужными формами, поэтому модель не видит весь пакет.

**Промпт и инструменты.** Оркестратор передаёт отобранные страницы в vLLM вместе с версионированным промптом и JSON-схемой ответа. Инструментов у модели нет: все сверки выполняет код после неё.

## №10. Выявление поддельных документов

Диаграмма: [10_container](diagrams/10_container.png).

**Где модель не нужна.** Без модели работают детерминированные сверки — с ГИР БО, оборотами по счёту, реквизитами и тождествами. Так же без модели идёт анализ файла: структура, метаданные, следы редактирования. Оригинал файла разбирается в изолированной песочнице.

**Где модель нужна.** Модель соотношений показателей работает только там, где сверять не с чем: для ИП на упрощёнке и клиентов без счёта в банке.

## Угрозы на границах доверия

| Граница | Угроза | Что делаем |
|---|---|---|
| **Д-1.** Клиент → кредитный конвейер → сервисы | Вредоносный файл; внедрённая в документ инструкция для модели (промпт-инъекция) | <ul><li>антивирус, обезвреживание файлов (CDR), лимиты размера;</li><li>оригиналы разбираются только в песочнице;</li><li>документ передаётся модели как данные, отдельно от инструкций;</li><li>у модели нет инструментов и сети, вывод ограничен JSON-схемой и сверяется с OCR-слоем и тождествами</li></ul> |
| **Д-2.** Публичные репозитории → репозиторий артефактов банка | Подменённые веса или веса с исполняемым кодом; лицензия запрещает коммерческое использование | <ul><li>веса только в safetensors, с фиксированным хешем и ревизией;</li><li>лицензия проверяется до загрузки;</li><li>SCA и SBOM для зависимостей;</li><li>сервер моделей без выхода в интернет</li></ul> |
| **Д-3.** Сервис → кредитный конвейер | Неверное значение доходит до кредитного решения; флаг становится отказом без участия человека (152-ФЗ, ст. 16) | <ul><li>значение без источника не предзаполняется;</li><li>флаг — только маршрут на проверку, отказ фиксирует сотрудник;</li><li>порядок фиксации согласуется с юристами</li></ul> |
| **Д-4.** ГИР БО ФНС → сервис №10 | Недоступность; изменение формата API или условий использования | <ul><li>кэш с датой актуальности и проверка схемы ответа;</li><li>при недоступности сверка помечается «не выполнена»;</li><li>условия использования подтверждают юристы</li></ul> |
