# №1. Угрозы на границах доверия

Номера соответствуют подписям ГД-N на диаграммах [прода](diagrams/01_container_prod.png), [пилота](diagrams/01_container_pilot.png) и [компонентов](diagrams/01_component_prioritization.png). Допустимость передачи данных (ГД-6) и использования сигнала KYC (ГД-1) определяют комплаенс, ИБ и юристы. Вопросы к ним — в разделе 4 паспорта.

| Граница | Угроза | Что делаем | Ответственный |
|---|---|---|---|
| **ГД-1.** KYC-платформа → система ПОД/ФТ → признаки | Неверный или подменённый уровень риска; отказ платформы; договор не разрешает использовать сигнал для обучения | <ul><li>проверка схемы и диапазона, при отказе — индикатор пропуска;</li><li>вклад признака ограничен;</li><li>дрейф сигнала — в мониторинге;</li><li>право использовать сигнал подтверждают юристы</li></ul> | Владелец сервиса; право на сигнал — юристы |
| **ГД-2.** DWH → конвейер признаков | Избыточный доступ; банковская тайна и ПДн в логах; клиент подбирает назначение платежа под словари типологий | <ul><li>витрина read-only с минимумом полей, учётная запись без права записи;</li><li>текст назначения платежа не попадает в логи и факторы;</li><li>словари не публикуются, признаки опираются и на суммы, частоты, граф</li></ul> | Владелец сервиса, ИБ |
| **ГД-3.** Сервис → система ПОД/ФТ | Ошибочный или подменённый ответ прячет операции в хвост очереди, в том числе через подмену версии модели; факторы раскрывают клиенту факт проверки | <ul><li>проверка контракта до публикации;</li><li>полосы A и B не зависят от модели, нижняя граница по сигналу правила;</li><li>выкатка с утверждением двух лиц, артефакты подписаны;</li><li>писать в топик приоритетов может только сервис (Kafka ACL);</li><li>факторы — из справочника и только в системе ПОД/ФТ</li></ul> | Владелец сервиса; выкатка — старший эксперт и ответственный сотрудник по ПОД/ФТ |
| **ГД-4.** Сотрудник → сервис разметки | Неверные метки отравляют обучение и оценку | <ul><li>двойная разметка, kappa по каждому разметчику, аудит старшим экспертом;</li><li>ролевой доступ;</li><li>метки не удаляются, только исправляются с указанием причины</li></ul> | Старший эксперт |
| **ГД-5.** Публичные репозитории → репозиторий артефактов банка | Вредоносная или уязвимая библиотека, подменённый образ | <ul><li>только зеркало банка, версии и хеши зафиксированы;</li><li>SCA, SBOM, подпись образов;</li><li>готовых внешних весов нет;</li><li>прод без выхода в интернет, облако пилота получает образы только из репозитория банка</li></ul> | ML-команда, ИБ |
| **ГД-6.** Банк → облако пилота | Повторная идентификация клиента; доступ администраторов провайдера; утечка при передаче | <ul><li>минимум полей, токены HMAC с ключом в банке, суммы округлены, текст — только числовыми индикаторами;</li><li>ГОСТ-VPN, бакет шифруется ключом банка;</li><li>по окончании пилота данные удаляются с актом;</li><li>старт только после вердикта комплаенса и ИБ</li></ul> | Владелец сервиса, ИБ; допуск к запуску — комплаенс |
| **ГД-7.** Облако пилота → банк | Подмена или порча оценок | <ul><li>подпись и контрольные суммы файла;</li><li>проверка схемы и полноты по выгруженным токенам, сверка распределения;</li><li>при нарушении файл отклоняется, а очередь работает по baseline</li></ul> | Владелец сервиса |
