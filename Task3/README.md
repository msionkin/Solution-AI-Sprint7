| Файл | Содержание |
|---|---|
| [01_flagship_architecture.md](01_flagship_architecture.md) | №1: звенья и их ответственность, полосы очереди A/B/C, режим обработки (ночной пересчёт + микропакет 15 мин), уровень автоматизации, пилот |
| [02_flagship_contract_fallback.md](02_flagship_contract_fallback.md) | №1: выходной контракт, проверки до публикации, отсутствие данных, фолбэк по кодам причин |
| [03_flagship_monitoring.md](03_flagship_monitoring.md) | №1: сигналы, пороги и реакции по слоям (вход, модель, очередь, операционный, бизнес); повторная проверка и откат |
| [04_flagship_trust_boundaries.md](04_flagship_trust_boundaries.md) | №1: угрозы на границах доверия ГД-1…ГД-7 |
| [05_documents_architecture.md](05_documents_architecture.md) | №18 и №10: где модель, а где код, получение контекста, промпт и инструменты; угрозы на границах Д-1…Д-4 |
| [diagrams/](diagrams/) | Исходники C4-PlantUML и PNG: `01_*` — №1, `18_*`, `10_*` — №18 и №10 |

## Сокращения

| Сокращение | Расшифровка |
|---|---|
| CDR | Content Disarm and Reconstruction — обезвреживание файлов |
| DLQ | Dead Letter Queue — очередь необработанных сообщений |
| DWH | Корпоративное хранилище данных |
| HMAC | Хеш с секретным ключом, используется для псевдонимизации |
| KYC | Проверка и оценка риска клиента |
| LLM, VLM | Большая языковая модель; модель, работающая с изображением и текстом |
| OCR | Распознавание текста на изображении |
| PSI | Population Stability Index — индекс сдвига распределения |
| SBOM, SCA | Перечень компонентов сборки; анализ уязвимостей зависимостей |
| SHAP | Метод оценки вклада признаков в оценку модели |
| ГД, Д | Граница доверия на диаграммах №1 и №18/№10 |
| ГИР БО | Государственный информационный ресурс бухгалтерской отчётности ФНС |
| ПВК | Правила внутреннего контроля |
| ПДн | Персональные данные |
| ПОД/ФТ | Противодействие отмыванию доходов |
