## Полосы очереди (№1)

Очередь финмониторинга делится на три полосы ([подробно](../Task3/01_flagship_architecture.md)):
- **A** (`URGENT`) — обязательные по ПВК и приостановленные операции; порядок по сроку, модель не влияет.
- **B** (`CONTROL_SAMPLE`) — случайная контрольная выборка для несмещённой оценки модели; оценка только пишется в журнал.
- **C** (`RANKED`) — остальные операции в порядке приоритета модели.
